FRD — 현장별 공정·기성 대시보드

한눈에 보기

  • 기능 12개를 표 한 줄씩 정리합니다. 사용자가 하는 일, 프로그램이 하는 일, 화면 결과, 오류일 때를 적습니다.
  • 역할은 사용자, 프로그램(계산·검사), AI(설명) 세 가지입니다. 숫자는 프로그램만 계산하고, AI는 기록을 근거로 설명만 합니다.
  • 흐름은 6개입니다. 자료 가져오기, 점검 현장과 이유 확인, CSV 내보내기, AI에게 묻기, 잘못된 파일 거부, 필터 변경입니다.
  • 계산 규칙은 data/검산표.md의 숫자로 예시를 붙입니다. 예: 9월 기성률 424,063.4 / 630,700 × 100 = 67.2%.
  • 앱은 처음에 자료가 없는 상태로 열립니다. 파일을 가져온 뒤에 2026년 9월·전체 현장이 보입니다.
자료는 교육용 가상 자료입니다. 현장명·계약·실적·기록은 실제 동일토건의 것이 아닙니다. 단위는 금액 백만원, 비율 %, 공정차이 pp입니다. (AI 결정)은 문서에 정해져 있지 않아 AI가 정한 부분입니다.

1. 기능별 표

번호 기능 사용자가 하는 일 프로그램이 하는 일 화면에 보이는 결과 오류·예외일 때
F1 파일 검사 자료 가져오기 페이지에서 CSV 또는 JSON 파일을 고릅니다. 15개 열이 모두 있는지, 숫자가 유한한 값이고 범위 안인지, 같은 월·현장 중복이 없는지 검사합니다. 같은 현장의 현장명·지역·유형·계약금액·착공일·계약상 준공일이 전 기간 같은지, 착공일이 계약상 준공일보다 앞서고 월말 기준일이 착공 전이 아닌지 확인합니다. 누적 공정률·누적기성액이 줄어드는 곳이 있으면 오류로 봅니다. JSON이면 metadata의 schemaVersion 2.0·단위·필수 열을 확인합니다. 검사 통과 시 F2의 미리보기로 이어집니다. CSV에는 메타데이터가 없어서 "설명서의 단위와 열 기준을 따른다"고 안내합니다. 빈 문자열·누락을 0으로 바꾸지 않고 오류로 표시합니다. 오류는 파일 행 번호(헤더가 1행)·열 이름·이유를 최대 10건 보여주고, 더 있으면 "외 N건"으로 표시합니다 (AI 결정). 가져오기 오류 화면에 "지금 자료는 그대로 유지됩니다"를 함께 보여줍니다. 월별 누락만 있으면 경고하고 "확인 가능한 행만 집계했다"고 표시합니다.
F2 미리보기·전체 교체 미리보기를 보고 "가져오기" 또는 "취소"를 누릅니다. 가져오기를 누르면 지금 자료를 새 자료 전체로 바꿉니다. 이어 붙이지 않습니다. 선택을 2026-09·전체 현장으로 초기화합니다. 행 수·현장 수·월 범위와 처음 5행을 보여줍니다 (AI 결정). 완료 후 현황 요약(2026-09)이 열립니다. 취소하면 지금 자료를 그대로 둡니다. CSV 다음 같은 JSON을 가져와도 144행입니다(288행 아님).
F3 필터 선택 월·지역·공사 유형·현장을 고릅니다. 선택한 범위로 숫자·표·추이·CSV·AI를 모두 다시 계산합니다. 선택한 현장이 지역·유형 변경으로 범위에서 빠지면 현장 선택을 전체로 되돌립니다. 페이지를 옮겨도 선택을 유지합니다 (AI 결정). 현황 요약·현장별 비교표·AI에게 묻기가 같은 범위를 표시합니다. 지역·유형·현장 선택은 그 범위 안에서 고를 수 있는 값만 보여줍니다. 선택 범위에 자료가 없으면 0% 대신 "자료 없음·계산 불가"를 보여줍니다.
F4 큰 숫자 4개 현황 요약을 봅니다. 선택 월·범위의 전체 기성률, 계획 공정률, 실제 공정률, 공정차이를 계산합니다. 2026-09·전체 현장 기준 67.2% · 73.2% · 71.2% · -2.0pp. 가까이에 정상·주의·점검 곳 수(6·3·3)를 함께 보여줍니다 (AI 결정). 분모가 없거나 자료가 없으면 "계산 불가"입니다.
F5 추이·월별 기성 현황 요약 아래쪽 차트를 봅니다. 시작 월(2025-10)부터 선택 월까지 매월 같은 범위로 계획·실제 공정률(계약금액 가중)과 당월기성액을 따로 집계합니다. 계획·실제 공정률 두 선과 월별 당월기성액 막대. 2026-09 선택 시 12개월 표시. 첫 달(2025-10)의 막대는 "계산 불가"로 표시하고 누적액으로 대신하지 않습니다. 그 달에 선택 범위의 자료가 없으면 해당 월을 "자료 없음"으로 표시합니다.
F6 12개 현장 비교 요약표 첫 화면 맨 위의 표를 봅니다. 선택 월의 현장별 계획·실제 공정률, 공정차이, 기성률, 상태를 계산합니다. 현장 ID(A~L) 순으로 보여줍니다 (AI 결정). 열: 현장(ID·이름) · 상태 · 계획 · 실제 · 공정차이 · 기성률. 9월 전체는 12행. 필터 결과가 없으면 "자료 없음"입니다.
F7 점검 순위 점검 순위 목록을 보고 줄을 누릅니다. 선택 월·범위의 점검 현장(-5pp 이하)을 공정차이가 작은 순, 같으면 현장 ID 순으로 나열합니다. 줄을 누르면 F8 비교표 페이지로 이동하고 그 현장 줄을 강조·펼칩니다. 한 줄: 현장명 · 계획 % · 실제 % · 공정차이 pp · 기성률 %. 9월은 D(-10.7pp) → I(-7.6pp) → K(-5.4pp). 점검 현장이 없는 범위(예: 2025-10)는 "점검 대상 없음" 상태를 보여줍니다.
F8 현장별 비교표 비교표 페이지에서 행을 펼치거나 접습니다. 선택 월·범위의 현장별 값을 계산하고, 행을 펼치면 해당 월 기록을 같은 페이지 안에서 보여줍니다. 열: 현장 · 지역 · 유형 · 당월 주요 공종 · 계약금액 · 누적기성액 · 기성률 · 계획 · 실제 · 공정차이 · 당월기성액 · 상태. 펼침: 공사기간(착공일~계약상 준공일) · 기록된 상황 · 대응 계획. 첫 달의 당월기성액은 "계산 불가". J의 7월 0.0은 정상값으로 표시합니다. 계약상 준공일에는 "예정일이며 실제 완료일이 아님"을 붙입니다 (AI 결정).
F9 CSV 내보내기 "내보내기"를 누릅니다. 선택 월의 선택 범위 행만 내보냅니다. 원본 15개 열 뒤에 기성률(%) · 공정차이(pp) · 상태 · 당월기성액(백만원) 4개 열을 더합니다 (AI 결정). 숫자와 단위를 유지하고 UTF-8 BOM으로 엑셀에서 한글이 깨지지 않게 합니다. 파일이 내려받아집니다. 9월 D만 선택하면 헤더 아래 1행, 9월 인천·공동주택이면 2행. 당월기성액을 계산할 수 없으면 칸에 "계산 불가"를 적고 0·빈칸으로 바꾸지 않습니다 (AI 결정). 내보낼 행이 없으면 "내보낼 자료가 없습니다"를 안내합니다.
F10 AI 질문 보내기 AI에게 묻기 페이지에서 예시 질문을 고르거나 질문을 입력해 보냅니다. 서버에서 Gemini API를 호출합니다. 선택 월 원문 행과 프로그램이 계산한 지표를 구분해서 보냅니다. 질문마다 시작 월~선택 월 월별 요약을 함께 보내고, 현장을 하나 고르면 그 현장의 월별 기록도 보냅니다 (AI 결정). 질문은 최대 500자입니다 (AI 결정). 위쪽에 지금 범위(월·지역·유형·현장)를 표시합니다. 예시 질문: "D가 늦어진 원인과 대응은?", "K의 점검 이유와 기록된 대응은?", "실제 준공일·미수금은?". 응답 중에는 "AI 답변 기다리는 중"을 보여줍니다. API 키 없음·한도 초과·30초 시간 초과면 "AI 연결 실패"를 보여주고, 대시보드와 CSV는 계속 쓸 수 있다고 안내합니다 (시간 제한은 AI 결정). 자료 없음 상태에서는 질문을 보낼 수 없고 가져오기 안내를 보여줍니다.
F11 AI 답변 표시 답변과 근거를 읽습니다. 답변에 기준 월·siteId·근거 숫자·참고 기록 필드(기록된 상황·대응 계획) 또는 월별 요약을 표시합니다. 필터가 바뀌면 이전 답변을 지우고, 요청 중 범위가 바뀌면 늦게 온 이전 응답을 새 범위에 표시하지 않습니다. 기록된 상황은 "기록된 상황", 대응 계획은 "계획된 대응"으로 설명합니다. 계약상 준공일은 계약상 일정으로만 안내합니다. 실제 준공일·미수금·수금액·기상 실측처럼 자료에 없는 내용은 "자료 없음"이라고 답합니다. 보낸 범위 밖의 월·현장을 물으면 전달한 자료 범위를 안내하고 숫자·원인을 만들지 않습니다 (AI 결정). 모의 응답이면 "모의 응답"이라고 표시합니다.
F12 상태 화면 5개 해당 상태가 되면 화면을 봅니다. 상태에 맞는 화면으로 바꿉니다. 아래 표 참고. —

2. 역할별 표

역할 맡는 일 맡지 않는 일
사용자 파일 선택, 가져오기·취소 결정, 월·지역·유형·현장 선택, 점검 순위 줄 선택, 행 펼침, CSV 내보내기, AI 질문 입력과 답변 판단 숫자 계산, 상태 판정, 파일 검사
프로그램(계산·검사) 파일 검사, 기성률·공정률·공정차이·상태·당월기성액 계산, 점검 순서 정렬, 필터 적용, 차트·표 데이터 만들기, CSV 만들기, AI에 보낼 자료 구분해서 만들기, 이전 답변 지우기 원인 추정, 기록에 없는 내용 만들기, 원본 자료 수정
AI(설명) 프로그램이 계산한 숫자와 기록된 상황·대응 계획을 근거로 설명하기, 근거 표시, 자료에 없는 내용은 "알 수 없음"으로 답하기 숫자 계산, 상태 판정, 원인·완료 여부 확정, 실제 준공일·미수금 답변, 일정 예측

3. 흐름별 표

흐름 순서 (① → ② → ③) 거치는 화면 끝났을 때 결과
자료 가져오기 ① 앱 열기 → ② 파일 선택 → ③ 검사 결과·미리보기 확인 → ④ 가져오기 자료 없음 → 자료 가져오기 → 현황 요약 144행이 들어오고 2026-09·전체 현장 현황이 보입니다.
점검 현장과 이유 확인 ① 현황 요약에서 점검 순위 확인 → ② D 줄 클릭 → ③ 비교표에서 강조된 D 줄의 펼침 기록 읽기 현황 요약 → 현장별 비교표 D의 공사기간·기록된 상황·대응 계획이 같은 페이지에 펼쳐집니다.
CSV 내보내기 ① 월·지역·유형·현장 선택 → ② 내보내기 → ③ 엑셀에서 열기 현황 요약 또는 현장별 비교표 선택 범위의 행과 4개 추가 열이 있고 한글이 깨지지 않습니다.
AI에게 묻기 ① 범위 선택 → ② AI에게 묻기에서 범위 확인 → ③ 예시 질문 선택 또는 입력 → ④ 답변과 근거 확인 AI에게 묻기 답변과 기준 월·현장·근거 숫자·기록 필드가 보입니다. 범위를 바꾸면 답변이 사라집니다.
잘못된 파일 거부 ① 정상 자료 가져오기 → ② 오류 파일 선택 → ③ 오류 안내 확인 자료 가져오기 어느 행의 무엇이 문제인지 보이고, 지금 자료와 9월 67.2%가 유지됩니다.
필터 변경 ① 지역 또는 유형 변경 → ② 선택 현장이 범위에서 빠지면 현장을 전체로 되돌림 → ③ 모든 화면이 같은 범위로 갱신 모든 페이지 숫자·표·차트·CSV·AI 범위가 같습니다. 이전 AI 답변은 지워집니다.

4. 계산 규칙 표

모든 계산은 중간 반올림 없이 하고, 마지막에 %·pp·금액을 소수 첫째 자리로 반올림합니다. 전체 공정차이는 화면에 반올림된 두 공정률을 다시 빼지 않습니다. 기성률·공정차이·상태는 원본에 저장하지 않고 프로그램이 계산합니다.

항목 계산 방법 예시 (검산표 숫자)
