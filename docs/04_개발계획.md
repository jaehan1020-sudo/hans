# 개발 계획 — 현장별 공정·기성 대시보드

## 한눈에 보기

- EPIC 3개, Story 12개입니다. 각 EPIC이 끝나면 브라우저에서 바로 볼 수 있는 결과가 있습니다.
- 순서: ① 자료 가져오기·필터·현황·추이 → ② 점검 현장·기록 펼침·CSV → ③ 근거를 보여주는 AI 질의.
- EPIC마다 자동 검사(Vitest·타입 검사)를 돌린 뒤, 학습자가 브라우저에서 확인할 행동과 결과를 하나씩 확인합니다.
- 학습자가 "확인했다"고 답하기 전에는 `05_테스트결과.md`에 완료로 적지 않습니다.
- GitHub 저장과 Vercel 배포는 계획에 넣지 않았습니다. 로컬 검증을 보고한 뒤 멈추고, 사용자가 각각 별도로 요청한 뒤에만 진행합니다.

> 기준 문서: `실습조건.md`, `작업규칙.md`, `01_PRD.md`, `02_FRD.md`, `03_TRD.md`, `design` 폴더 시안. 자료는 교육용 가상 자료입니다.

## 2. Story 표

### EPIC 1. 자료 가져오기·필터·현황·추이

| 번호 | 사용자가 할 수 있는 일 | 확인할 행동 | 보여야 할 결과 |
|---|---|---|---|
| S1 | 앱을 열어 4개 메뉴와 "자료 없음" 상태를 본다. | 브라우저에서 `http://localhost:3000`을 연다. 왼쪽 메뉴의 현황 요약·현장별 비교표·자료 가져오기·AI에게 묻기를 차례로 누른다. | 화면 가운데에 "자료를 먼저 가져오세요"와 "자료 가져오기로 가기" 버튼이 보인다. 메뉴를 누르면 해당 페이지로 바뀐다. |
| S2 | 파일을 고르면 검사 결과를 본다. | 자료 가져오기에서 `data/검증용_오류데이터/오류_공정률101.csv`를 고른다. | 빨간 오류 안내에 "134행"·"actualProgress"·이유가 보이고 "지금 자료는 그대로 유지됩니다"가 있다. 가져오기 버튼은 눌리지 않는다. |
| S3 | 미리보기를 보고 가져오기 또는 취소를 누른다. | `data/현장공정기성.csv`를 고른다. 먼저 "취소"를 누르고, 다시 고른 뒤 "가져오기"를 누른다. | 미리보기에 "144행·12개 현장·2025-10~2026-09"와 처음 5행이 보인다. 취소하면 자료 없음이 유지된다. 가져오기를 누르면 현황 요약으로 이동한다. 이어서 같은 내용의 `.json`을 가져와도 "144행"이다. |
| S4 | 월·지역·공사 유형·현장을 고른다. | 현황 요약에서 지역을 "인천", 유형을 "공동주택"으로 고른 뒤 현장을 "A"로 고른다. 이어서 지역을 "경기"로 바꾼다. | 인천·공동주택에서는 현장 선택에 A·G만 나온다. 경기로 바꾸면 A·G가 범위에서 빠져 현장 선택이 "전체"로 돌아간다. |
| S5 | 큰 숫자 4개를 본다. | 처음 상태(2026-09, 전체)에서 맨 위 숫자를 본다. 월을 "2025-10"으로 바꾼다. | 9월: 기성률 67.2%, 계획 73.2%, 실제 71.2%, 공정차이 -2.0pp, 정상 6·주의 3·점검 3. 2025-10: 계획 19.4%, 실제 19.6%, 공정차이 0.2pp. 자료가 없는 범위는 0%가 아니라 "계산 불가". |
| S6 | 추이와 월별 기성을 본다. | 월 "2026-09"에서 아래 차트를 본다. 월을 "2025-10"으로 바꾼다. | 9월: 12개월 선과 막대, 9월 당월기성액 28,878.7백만원. 2025-10: 막대 자리에 "계산 불가" 표시, 누적액을 대신 쓰지 않는다. |

### EPIC 2. 점검 현장·기록 펼침·CSV

| 번호 | 사용자가 할 수 있는 일 | 확인할 행동 | 보여야 할 결과 |
|---|---|---|---|
| S7 | 12개 현장 비교 요약표를 본다. | 현황 요약 맨 위 표를 본다. | 현장 A~L 12행, 열은 현장·상태·계획·실제·공정차이·기성률. D는 점검 -10.7pp, 기성률 69.4%. 상태는 글자와 색이 함께 보인다. |
| S8 | 점검 순위를 보고 줄을 누른다. | 점검 순위에서 "D"를 누른다. 월을 "2025-10"으로 바꿔 점검 순위를 본다. | D → I → K 순서로 현장명·계획·실제·공정차이·기성률이 보인다. D를 누르면 현장별 비교표로 이동해 D 줄이 강조되고 펼쳐진다. 2025-10에는 "점검 대상 없음"이 보인다. |
| S9 | 비교표에서 행을 펼치고 접는다. | 현장별 비교표에서 J를 펼치고 월을 "2026-07"로 바꾼다. | 펼침에 공사기간(착공일~계약상 준공일, "예정일이며 실제 완료일이 아님")·기록된 상황·대응 계획이 보인다. J의 7월 당월기성액은 0.0이고 기록에 "기성 확인 서류 보완" 계열 내용이 있다. 2025-10의 당월기성액은 "계산 불가". |
| S10 | 지금 범위를 CSV로 내려받는다. | 현장을 "D"로 골라 "CSV 내보내기"를 누르고 엑셀로 연다. 이어서 인천·공동주택으로 바꿔 내려받는다. | D만: 헤더 아래 1행, 열 끝에 기성률(%)·공정차이(pp)·상태·당월기성액(백만원)이 있고 D는 69.4 · -10.7 · 점검 · 3339.6. 인천·공동주택: 2행(A·G). 한글이 깨지지 않는다. |

### EPIC 3. 근거를 보여주는 AI 질의

| 번호 | 사용자가 할 수 있는 일 | 확인할 행동 | 보여야 할 결과 |
|---|---|---|---|
| S11 | AI에게 질문하고 근거와 함께 답변을 읽는다. | AI에게 묻기에서 "D가 늦어진 원인과 대응은?"을 누른다. 이어서 "실제 준공일·미수금은?"을 누른다. | 위쪽에 지금 범위가 보인다. D 답변에는 기준 월(2026-09)·현장 D·근거 숫자(계획 86.5%·실제 75.8%·-10.7pp·기성률 69.4%)와 기록된 상황·계획된 대응이 있다. 준공일·미수금은 "자료 없음", 계약상 준공일은 계약상 일정으로만 나온다. |
| S12 | 범위를 바꾸거나 AI 연결이 안 될 때 상태를 본다. | 답변이 나온 뒤 월을 바꾼다. `.env.local`의 키가 비어 있거나 모의 응답 모드가 꺼진 상태에서 질문한다. | 월을 바꾸면 이전 답변이 사라진다. 요청 중에는 "AI 답변 기다리는 중", 실패하면 "AI 연결 실패"와 "대시보드와 CSV는 계속 쓸 수 있습니다"가 보이고, 대시보드·CSV는 그대로 동작한다. 모의 응답일 때는 "모의 응답"이라고 표시된다. |

## 4. 진행 규칙

| 규칙 | 내용 |
|---|---|
| 완료 표시 | 학습자가 확인했다고 답한 뒤에만 `05_테스트결과.md`에 완료로 적는다. |
| 확인하지 못한 것 | 자동 검사로 확인하지 못한 것과 사람이 확인하지 않은 것은 "미확인"으로 따로 적는다. |
| 오류가 반복될 때 | 같은 오류가 세 번 반복되면 다른 방법을 제안한다. |
| 원본 자료 | `data/` 파일은 고치지 않는다. 오류 파일 시험도 원본 그대로 쓴다. |
| 저장·배포 | GitHub 저장과 Vercel 배포는 사용자가 저장소·프로젝트를 정해 따로 요청한 뒤에만 한다. 자동 실행 Story나 완료 조건에 넣지 않는다. |
