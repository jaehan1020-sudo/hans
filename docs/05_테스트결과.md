## 6. 알려 드릴 점 (보안)

- `.env.example`(GitHub에 올라가는 견본 파일)의 `GEMINI_API_KEY=` 뒤에 키로 보이는 값이 들어 있습니다. `.env.local`은 비어 있습니다. 값은 이 문서에 적지 않았고 파일도 고치지 않았습니다.
- GitHub 저장을 하기 전에 키를 `.env.local`로 옮기고 `.env.example`은 비워야 합니다.
